## Viesturs Olins

Throughout this project, I learned to use GitHub in a team environment properly for the first time, using issues, branches, pull requests, releases, and automated testing. This was the most valuable thing I took away. The most fun part was meeting on Zoom to work together, as online study can feel isolating, and collaborating as a team made the project feel less stressful. Working in a team also forced us to use GitHub correctly, since we couldn't just push to main branch as there would be conflicts. The most difficult part was also the team aspect, we had to work sequentially and ensure our code was always compatible with each other. An important skill I developed was writing tests and maintaining good coverage throughout the project, as well as the habit of continuous testing.
